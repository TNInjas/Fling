# Security Policy

## Reporting a vulnerability

Do not open a public issue containing credentials, private code, exploit details that could affect other users, or sensitive system information.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainer through a verified private channel listed on the repository owner's GitHub profile.

## Scope

This project primarily distributes Markdown instructions, templates, and small shell scripts. Security reports may include:

- Unsafe or destructive installer/uninstaller behaviour.
- Path handling or permission issues.
- Accidental exposure or deletion of user configuration.
- Instructions that encourage unsafe handling of credentials or external services.

## Supported versions

Security fixes are expected to target the latest published release. Older releases may not receive fixes.

Please include the package version, Antigravity CLI version, operating system, shell, exact reproduction steps, and sanitized output.
